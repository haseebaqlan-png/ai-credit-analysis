# V4 Changelog

## 4.0.0
- Rebuilt the platform around document-first underwriting.
- Added multi-document upload and parsing.
- Added automatic document classification.
- Added financial field extraction with source trace and confidence.
- Added mandatory human validation before analysis.
- Added cash-flow-first sizing, working-capital need, leverage and collateral constraints.
- Added stress testing and draft credit memorandum.
- Added data-quality gating and auditability concepts.
- Removed dependence on manual-only financial data entry as the primary workflow.
